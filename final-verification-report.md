*   **@font-face implementation:**
    ```typescript
    // Wrap the base64 font in url() if it doesn't have it
    const fontSrc = fontBase64 
        ? (fontBase64.startsWith('url') ? fontBase64 : `url('${fontBase64}')`)
        : "url('/fonts/Avingal.ttf')";

      font-family: "Avingal";
      src: ${fontSrc} format("truetype");
    ```

    The attributes `textLength` and `lengthAdjust` **have been completely removed**. There are **no** `transform="scale(...)"` directives.

*   **Mathematical Font Scaling:**
    ```typescript
    const MAX_WIDTH = 1300;
    const AVG_CHAR_WIDTH_RATIO = 0.47;
    let fontSize = 176;
    const estimatedWidth = cleanName.length * fontSize * AVG_CHAR_WIDTH_RATIO;
    
    if (estimatedWidth > MAX_WIDTH) {
        fontSize = Math.floor(176 * (MAX_WIDTH / estimatedWidth));
        if (fontSize < 60) fontSize = 60; // minimum legible size
    }
    ```
    This mathematically ensures short names like "Santhosh S" remain at exactly `176px`, while exceptionally long names gracefully reduce font-size to stay within the ~1300px safe zone without horizontal squishing.
